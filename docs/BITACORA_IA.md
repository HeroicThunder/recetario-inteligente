# Bitácora de uso de Inteligencia Artificial — SazónIA

## 1. Objetivo

Documentar el uso de herramientas de inteligencia artificial durante el desarrollo de SazónIA, un recetario inteligente desarrollado como proyecto académico.

## 2. Herramientas utilizadas

- **ChatGPT:** Se utilizó como herramienta de apoyo para resolver dudas técnicas, analizar errores, orientar la implementación de funcionalidades, revisar fragmentos de código y elaborar documentación.
- **Gemini API:** Se integró en la aplicación para generar sugerencias y recetas a partir de los ingredientes disponibles o de un ingrediente seleccionado por el usuario.

## 3. Actividades apoyadas por IA

| Actividad | Herramienta | Uso |
|---|---|---|
| Planeación de funcionalidades | ChatGPT | Organizar los módulos y el flujo de la aplicación. |
| Diseño y estructura | ChatGPT | Recibir orientación sobre pantallas, componentes y organización del proyecto. |
| Desarrollo | ChatGPT | Resolver dudas sobre React Native, Expo, TypeScript y SQLite. |
| Corrección de errores | ChatGPT | Analizar mensajes de error y proponer soluciones. |
| Generación de recetas | Gemini API | Producir recetas a partir de los ingredientes proporcionados. |
| Documentación | ChatGPT | Apoyar en la elaboración de documentos del proyecto. |

## 4. Ejemplos de uso

- Se utilizó ChatGPT para identificar y corregir errores durante la integración de módulos.
- Se recibió orientación para implementar el almacenamiento local de información mediante SQLite.
- Se utilizó Gemini API para incorporar la generación de recetas dentro de la aplicación.
- Se recibió apoyo para implementar la exportación y compartición de recetas en formato PDF.

## 5. Validación de resultados

Las sugerencias proporcionadas por las herramientas de IA fueron revisadas y probadas durante el desarrollo. Las soluciones propuestas no se incorporaron automáticamente: se verificó su funcionamiento dentro del proyecto y se realizaron ajustes cuando fue necesario.

## 6. Limitaciones

Las respuestas generadas por IA pueden contener errores o proponer soluciones que no se adapten completamente al proyecto. Por esta razón, fue necesario revisar el código, realizar pruebas y validar los resultados antes de conservar los cambios.

## 7. Conclusión

El uso de herramientas de inteligencia artificial facilitó el desarrollo de SazónIA al proporcionar orientación técnica, ayudar a resolver problemas y permitir la incorporación de generación automática de recetas. Sin embargo, las decisiones finales y la validación del funcionamiento de la aplicación estuvieron a cargo del desarrollador.
