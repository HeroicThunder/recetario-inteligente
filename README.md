# 🍽️ SazónIA — Recetario Inteligente

SazónIA es una aplicación móvil desarrollada como proyecto académico que combina la administración de ingredientes con inteligencia artificial para ayudar a los usuarios a descubrir y organizar recetas.

## ✨ Características principales

- **Despensa:** administración de ingredientes disponibles.
- **Lista de compras:** organización de ingredientes que se necesitan comprar.
- **Generación inteligente de recetas:** sugerencias mediante Gemini API, utilizando los ingredientes disponibles o uno seleccionado.
- **Favoritos:** almacenamiento de recetas preferidas.
- **Fotografías:** posibilidad de agregar imágenes a las recetas.
- **Exportación PDF:** generación y compartición de recetas en formato PDF.
- **Almacenamiento local:** persistencia de información mediante SQLite.

## 🛠️ Tecnologías utilizadas

- React Native
- Expo
- TypeScript
- Expo Router
- SQLite
- Gemini API

## 📱 Plataforma

Aplicación desarrollada para dispositivos Android.

## ⚙️ Instalación y ejecución

1. Clonar el repositorio:

   ```bash
   git clone https://github.com/HeroicThunder/recetario-inteligente.git
   ```

2. Entrar a la carpeta:

   ```bash
   cd recetario-inteligente
   ```

3. Instalar las dependencias:

   ```bash
   npm install
   ```

4. Configurar las variables de entorno necesarias para Gemini API, siguiendo la configuración del proyecto.

5. Iniciar Expo:

   ```bash
   npx expo start
   ```

6. Escanear el código QR con Expo Go para probar la aplicación, siempre que la versión instalada sea compatible.
